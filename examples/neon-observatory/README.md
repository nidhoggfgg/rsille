# Neon Observatory / 霓虹观测站

一个只使用 rsille 公开接口的 inline 终端 demo：环形行星、光子隧道、霓虹山谷、螺旋星系、液态金属环面和湖畔极光。所有画面均在 CPU 上实时计算，支持配色、暂停和时间倍率，无需图片素材或网络服务。

从仓库根目录运行：

```sh
cargo run --release --manifest-path examples/neon-observatory/Cargo.toml
```

推荐使用支持 True Color 和 Unicode 盲文字符的终端与等宽字体，界面左对齐，宽度最多 **140 列**，窄窗口随可用宽度缩小；默认占用 **40 行**，使用普通终端屏幕，不进入备用全屏缓冲区；保留之前的终端输出，退出后回到命令行。窗口不足 40 行时按可用高度显示。

在 140×40 的窗口中，主画布为 **138×31 个字符**，对应 **276×124 个盲文点**；相较原来的 100×28 布局，可绘制点数约为 **2.3 倍**，用于呈现更细的云带、环面高光、星云和极光褶皱。

## 操作

| 输入 | 行为 |
| --- | --- |
| `1`–`6` | 切换行星、隧道、地形、星系、环面、极光；播放揭幕效果 |
| `p` | 暂停／恢复模拟时间，恢复时接续原位置 |
| `c` | 切换青紫、落日、极光三组配色 |
| `s` | 切换 1×、2×、0.5× 时间倍率 |
| `?` | 打开／关闭带淡入效果的帮助弹窗 |
| `Tab` / `Shift+Tab`、`Enter` / 空格 | 仅在暂停、配色、速度控件间移动焦点并激活；帮助弹窗内聚焦关闭按钮 |
| 鼠标左键 | 点击控制栏按钮 |
| `q` / `Esc` | 退出 |

场景按钮设置为 `.focusable(false)`：鼠标可以直接点击，数字快捷键随时有效，Tab 和鼠标都不会把键盘焦点移到场景按钮。控制栏分为场景选择和播放控制两行；小窗口允许文字和按钮裁剪，快捷键仍可使用。右侧模拟遥测和波形面板已移除，主画布使用界面宽度，整体最多 140 列，不随宽屏终端无限拉伸。

六种场景共用模拟时间，暂停和调速对全部场景生效。

| 场景 | 画面 |
| --- | --- |
| Orbit | 有前后遮挡的行星环、旋转云带、昼夜光照、大气边缘与运行中的卫星 |
| Warp | 扭转的隧道环、移动消失点、分层透视星流与逐渐拉长的光迹 |
| Terrain | 有遮挡与光照的起伏山谷、霓虹网格、扫描光带、条纹落日与远山雾层 |
| Galaxy | 连续的三旋臂星云、暗尘带、暖色星核与两千余颗旋转恒星 |
| Torus | 距离场光线步进、真实表面遮挡、镜面高光、流动刻线与环绕粒子 |
| Aurora | 三层褶皱光帘、紫色上缘、两层山脊剪影与流动的湖面倒影 |

[`scenes.rs`](src/scenes.rs) 负责场景公式，[`raster.rs`](src/raster.rs) 负责光能累加、辉光与曝光。各场景先绘入浮点光照缓冲区，再通过 `Canvas::set_color` 写入每个采样点的颜色；Canvas 的内置 Braille 编码在输出时把每个 2×4 点的区域拟合为两种终端颜色。这样既保留盲文点的细节，也让行星表面、山体、星云与极光获得连续的色彩层次，避免后绘制的一个点改掉整格颜色。高亮经过柔和曝光映射，局部辉光只扩散明亮区域。Terrain 使用深度缓冲区遮挡后方山体，并按透视修正网格坐标，让网格与扫描光带贴合连续起伏的表面。

## 框架能力评估

结论：**当前框架已经能构建有视觉冲击力、可交互的终端界面，不需要先补齐一套基础设施。** 此 demo 没有引入其他 TUI 框架，也没有为绘制绕过 rsille 的渲染器。

| 能力 | 已有实现 | demo 中的用途 |
| --- | --- | --- |
| 高密度彩色绘图 | [`CanvasWidget`](../../src/tui/widgets/display/canvas.rs)、[`Canvas`](../../src/canvas/canvas.rs) | 每个字符单元 2×4 个盲文点与前景／背景双色，绘制六种动态场景 |
| 时间与动画 | [`App::on_frame`](../../src/tui/app.rs)、`FrameInfo::delta` | 时间驱动的旋转、隧道、地形与极光；暂停、倍率 |
| 组合与布局 | [`Widget::layout`](../../src/tui/widget.rs)、Flex、Panel | 常规组件加应用侧容器，限制 inline 宽度和首选高度，并按可用区域布局 |
| 单元格视觉特效 | [`VisualEffect`](../../src/tui/visual_engine/effect.rs) | 标题渐变、场景揭幕、弹窗淡入 |
| 键鼠与焦点 | Button、App 快捷键、Overlay 焦点约束 | 数字快捷键、跳过场景按钮的 Tab 顺序、鼠标控制与帮助弹窗 |
| 配色与主题 | [`Theme`](../../src/tui/style/theme.rs)、`with_theme_from` | 场景和按钮随状态同步换色 |
| 可重复验证 | [`Runtime`](../../src/tui/runtime/core.rs)、`ManualClock` | 无 TTY 驱动同一套应用代码，推进时间并检查真实帧 |

应用中的 `Dashboard` 只分配标题、两行控制栏、主画布和底栏；六种场景的绘制公式属于 demo 内容。rsille 提供的是绘图、布局与交互基础，并不内置这些 3D 场景或自动响应式断点。

仍需明确的边界：

- 这是字符网格上的终端图形。它没有提供网页／原生 GUI 级的任意字体、像素透明叠加或 GPU 3D 渲染；盲文字符内的点共享前景色。
- 画面的比例与颜色表现取决于终端和字体。demo 按常见的字符宽高比 1:2 设计，不自动探测物理字符尺寸。
- 特效和逐帧绘图会消耗 CPU；应用消息会重建描述树并使布局失效。框架已有绘制与布局失效区分，但本 demo 使用直观的应用状态更新方式。没有据此承诺固定帧率，也没有完成跨终端性能基准。
- 大量数据的图表、复杂 3D 场景、自动响应式组件等需要在这些基础能力上实现；它们不是本例的先决条件。

制作过程中修复了一个已有问题：离屏缓冲区保留源帧差分，使渐变等特效在后续新帧中跳过未变化的文字，导致标题消失。现在仍复用缓冲区分配，但不把上一源帧当作目标画面已保留内容的依据；同时添加了重复渲染回归断言。

## 验证与实际帧导出

```sh
cargo test --manifest-path examples/neon-observatory/Cargo.toml
cargo run --manifest-path examples/neon-observatory/Cargo.toml -- --headless
cargo clippy --manifest-path examples/neon-observatory/Cargo.toml --all-targets -- -D warnings
cargo run --release --manifest-path examples/neon-observatory/Cargo.toml -- --snapshot /tmp/neon.svg 4 12
cargo run --release --manifest-path examples/neon-observatory/Cargo.toml -- --benchmark
```

`--headless` 检查动画推进、标题持续显示、盲文输出、暂停、六种场景的绘图和切换、配色／倍率切换、弹窗、场景按钮跳过焦点、控制按钮键盘激活、鼠标点击后保留原焦点、多种窗口尺寸和退出。它使用手动时钟，不依赖真实睡眠或 TTY。

`--snapshot FILE.svg [1-6] [SECONDS]` 把 140×40 的实际 rsille Buffer 导出成 SVG；默认场景为行星，默认模拟时间为 12 秒。指定秒数可检查不同的旋转角度和动画位置。SVG 用于预览字符与前景／背景颜色；不同字体的字重和字形可能与终端略有差别。`crossterm` 仅用于 Canvas 颜色类型与导出缓冲区的颜色识别。

`--benchmark` 用手动时钟为每个场景预热 10 帧，再测量 90 帧的平均和 p95 耗时，覆盖应用更新、布局和实际 Buffer 渲染，不包含终端 I/O 或 SVG 导出。请使用 release 构建；测量结果仅代表本机 CPU 路径，不等于真实终端帧率。

测试还覆盖双色采样的颜色与点位、超出视口的长光迹裁剪、山体前后遮挡，以及全部场景在不同时间、三种配色和小尺寸下的绘制。相同模拟时间的场景必须得到完全相同的 Buffer，暂停时不会因重新采样产生随机闪烁。
