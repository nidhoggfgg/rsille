# Function Plotter / 函数绘图

[English](README.md) · 中文

一个直接在终端主屏幕运行的数学 REPL：用 `meval` 解析表达式，用 rsille 的 RGB 栅格和 Sixel 绘制函数。不实现符号代数或方程求解器；依赖只添加在本示例。

## 运行

在仓库根目录执行：

```sh
cargo run --release --features sixel --manifest-path examples/function-plotter/Cargo.toml -- --sixel
cargo run --release --features sixel --manifest-path examples/function-plotter/Cargo.toml -- --sixel --expr 'sin(x); cos(x); x^2/8'
cargo run --release --manifest-path examples/function-plotter/Cargo.toml -- --text-only
```

无参数显示帮助，建议使用 100×32 字符格。未指定 `--expr` 时，直接打开空白、无边框的 `In[1]:=` 输入框，不绘图、不添加历史、不提交。只有显式指定 `--expr` 才在启动时执行并提交图像或错误，然后打开空白 `In[2]:=` 提示符。以后每次执行都会把 `In[n]:=` 输入及其 `Out[n]=` 图像或错误留在终端历史中，再打开下一个空白提示符。使用现有无边框 `TextArea` 控件，限制为一行，不绘制外围方框或底线；编辑中和提交后的表达式均紧接在同一行的 `In[n]:=` 后。输入框与周围文字使用终端默认背景，光标和选区以下划线表示，不再使用背景色高亮；图像保留自身的背景色。`Out[n]=` 或预览标题下方先显示只读公式区，再显示图像；编辑输入仍保持线性文本。粘贴的 CRLF、CR、LF 换行转换为空格，保持单行输入。不使用备用屏幕，不再维护可滚动编辑的笔记本，也不保存会话。不能原地修改历史输出。

原生模式下，公式与曲线图共用公式内容所需的宽度（含内边距，并向上取整到完整字符格），不超过终端可用宽度；图像高度仍为 14 行，短公式对应的曲线图也会更窄。右侧未使用的空间保留终端背景，不绘制 Sixel。纯文本模式的曲线图仍最多 70 列。先布局，再按分配的列数/行数乘以真实字符格像素尺寸确定栅格大小；HalfBlock 字符预览使用 1×2 网格。因此 70×14 字符格在每格 8×16 像素时直接绘制 560×224 图像，字符预览则直接绘制 70×28 图像，没有中间图像或降采样。仅绘制普通函数时，图像有意填满可用矩形：采样得到的数学范围在调整尺寸时保持固定，但横纵比例随终端大小及字符格尺寸变化，两个轴的单位长度不保证相等。边距及网格密度按像素预算调整；仅在至少 160×80 时显示 3×5 像素数字刻度，更小时省略文字与边距以优先显示曲线。曲线使用约 1.5 个目标像素宽的抗锯齿圆头描边，与已有网格、坐标轴及先绘制的曲线混合。每条函数先累积覆盖率再混合，避免自适应细分接点重复叠加而变亮。端点圆头及边缘最多延伸 1.25 像素，小于描边覆盖范围的间隙无法保留；抗锯齿描边本身不增加函数采样，也不使用中间超采样图像或缩放。

针对细对角线看似断续的问题，测试确认旧的单像素 `y=x` 在 70×14 字符格、每格 18×40 和 20×40 像素时，源图像与采样输出均为八连通。Sixel 测试还解码实际渲染器输出，逐像素验证 RGB332 量化结果，确认旧路径和新抗锯齿路径都没有丢失像素且保持连通。证据支持单像素阶梯造成的视觉间隙，而不是这些尺寸下的编码丢点；截图的真实字符格尺寸和终端行为未知，因此不能声称复现了截图。详见 [英文诊断说明](README.md#stroke-diagnosis)。

UI 状态保存不可变的已解析函数源，而不是布局前生成的图像。每个源拥有以数学范围及目标像素尺寸为键的单项缓存，源身份由对象所有权区分。普通重绘及未编辑预览的提交复用缓存；调整尺寸时直接重新绘制，不重新解析。`meval` 绑定闭包不是 `Send`，因此采用 UI 线程内的 `Rc` 共享和 `RefCell` 缓存，不启动后台任务。替换源或进入下一提示符会释放旧缓存。

`--sixel` 是**用户明确确认**终端及复用器支持 Sixel、ED 2 和 **EL2 图形擦除**、图形随文本滚动、稳定调色板以及无滚屏的定位输出。程序不检测这些能力。此选项设置 `reliable_inline_erase` 并使用 `RequireSixel`，不静默降级。**滚动历史是否保留图像取决于终端**；提交帧并不保证 Sixel 图像在滚动后仍然可见。

启动时在输入读取前测量字符格像素尺寸，测量失败则报错。可用 `--cell-pixels WxH` 提供**真实的每格像素尺寸**，不是终端列数×行数。原生 Windows 没有查询回退。字体/DPI 改变后请重启。详见[栅格指南](../../docs/raster.md)。

## 二维公式输出

Sixel 预览和提交结果支持较小的上标幂、上下分式、带横线的根号、函数及嵌套括号；解析后的 `pi` 和 `theta` 显示为 π 和 θ。排版依据 `meval` 的 RPN 语法结构，不使用正则替换；多余括号和数字写法可能规范化，也可能增加显式分组括号。这只是类似 Mathematica 的显示方式，不支持其语法或符号排版系统。

使用 `rsille-typst` 调用真正的 Typst 排版和抗锯齿渲染，字体为 `typst-assets` 0.13.1 捆绑的 New Computer Modern Math。字号随字符格高度调整（12–40 像素），公式栅格按原始尺寸复制，不缩放。不需要外部 Typst/TeX 命令、系统字体搜索或运行时联网；引入 Typst 和字体资源后，首次构建开销会增加。公式颜色与分号分隔的曲线一致；极坐标标为 `r(θ)`，参数曲线的 `x(t)`、`y(t)` 两行使用一个大左花括号组成方程组，取值范围排在方程组右侧；极坐标的取值范围也紧接在方程后方，同排显示。原生模式下公式区与曲线图按内容等宽，未使用的终端宽度不计入两块栅格。原生输出采用 Typst 标准 `cases` 排版。文字回退使用两行大括号 ⎰/⎱，取值范围附在第一行右侧，方程之间不插空行；字符格模式无法将文字垂直居中于两行之间。普通函数的采样区间仍由 `--x-range` 控制。

纯文本模式显示可读的原始表达式行，不初始化字体、不编译公式。超过 128 个 RPN token、Typst 渲染失败或无法放入分配区域的公式会回退到文字，不影响有效表达式的绘图。每行公式最多 500,000 像素，原生模式公式区最多 12 个终端行；过长的回退文字和超出终端视口的内容可能被裁切。暂不支持公式自动换行或横向滚动。输入仍为 `meval` 语法，不接受 Typst 或 LaTeX：只将解析后的 token 转换为数学排版语法，标识符使用引号保护，避免执行用户提供的 Typst 代码。公式行按字符格高度缓存（也缓存失败），普通窗口尺寸变化只重新合成目标画布，不重复编译；未修改预览的提交复用缓存。下一提示符释放源持有的缓存，但 Typst 自身仍维护进程级缓存。

## 操作和表达式

- 输入框使用当前行的剩余宽度。超长表达式横向滚动以保持光标可见；**Home / End** 查看开头或末尾。隐藏文字仍属于草稿，预览和提交均使用完整输入。加宽终端后，只要宽度足够（包括一列光标），就会显示完整输入。
- 编辑或调取历史后，停止输入 500 毫秒即在输入框下方显示实时预览，不提交、不增加历史。等待期间清除旧图像和预览错误；空输入清除预览。预览错误不阻止提交。
- **Enter / F5** 立即执行并提交当前输入，无需等待预览。每次最多六条曲线，以 `;` 分隔，曲线颜色按输入顺序为青、橙、绿、粉、紫、黄。
- **上 / 下方向键** 调取最近 24 条已提交输入（包括错误输入）。在最新记录后再按下方向键恢复未完成的草稿。可修改调出的输入并作为新结果提交，不影响历史输出。
- **Esc** 退出。禁用鼠标捕获，使用终端自身的滚动历史操作，不提供应用内滚动或鼠标按钮。
- 单条输入最多 4096 字节。超长编辑显示错误，不会静默执行截断后的前缀；可编辑修正，或提交错误后重新输入。
- 应用仅保留当前结果和有上限的文本输入历史；打开下一提示符后释放旧图像。退出后不保存任何内容。

支持 `sin(x)`、`cos(x)`、`tan(x)`、`sqrt(x)`、`exp(x)`、`ln(x)`、`abs(x)`、`x^2`、常量 `pi` 和 `e`；乘法写作 `2*x`。可试：`1/x; tan(x)`、`sqrt(x); ln(x)`、`sin(x)*exp(-x^2/20)`。

绘图包含网格、零轴和数值刻度，采用有预算上限的自适应中点细分，非有限值及无法解析的间断区间不连线。但有限采样不是连续性证明，极窄特征和高频振荡可能遗漏。没有自动求根、积分、隐式曲线或符号求解功能。不兼容 Mathematica 的 `Plot[...]` 语法。

x 采样区间默认为 `[-10, 10]`，可用 `--x-range MIN MAX` 指定，例如 `--text-only --x-range -2 4 --expr '0.05*sin(x)'`。支持负数参数；端点必须有限、递增，且跨度有限。不能从任意表达式推断 x 区间。

y 范围在每次解析输入后估算一次，不随栅格尺寸变化：每条函数在 x 区间等距采样 1025 点，忽略非有限值。将各函数采样极值限制在第一/第三四分位数向外各延伸三倍四分位距的范围内，再合并各函数范围，两侧各增加 5% 留白。四分位距为零时使用四分位数本身。这能限制极点尖峰，但也可能裁掉真实窄峰或偏斜长尾，**不保证找到全部全局极值**。常量使用其绝对值的 5% 留白，零使用 ±1；全部样本非有限时回退到 `[-1, 1]`。不强制 y 范围包含零。刻度采用随范围变化的 1/2/5 步长，小范围使用相应精度的小数或科学计数法。未增加额外的 y 范围操作界面。

## 极坐标和参数方程

普通函数、极坐标和参数曲线可以用 `;` 混合在同一张图中，总数仍最多六条，颜色按输入顺序分配：

| 类型 | 语法 | 自由变量 |
| --- | --- | --- |
| 普通函数 | `sin(x)` | `x` |
| 极坐标 | `polar(1+cos(theta), 0, 2*pi)` | `theta`（弧度） |
| 参数方程 | `param(cos(t), sin(t), 0, 2*pi)` | `t` |

`polar(r, 起点, 终点)` 按 `(r*cos(theta), r*sin(theta))` 绘制，支持负半径。`param(x, y, 起点, 终点)` 绘制二维参数轨迹。区间必须显式提供，端点可使用 `2*pi` 等常量表达式，必须有限、递增且跨度有限；不能包含自由变量。支持表达式内部的多参数函数，例如 `polar(max(1, cos(theta)), 0, 2*pi)`。`--x-range` 仅控制普通函数的采样区间，不控制 `theta` 或 `t`。

可以直接粘贴以下表达式：

```text
polar(2*cos(5*theta), 0, 2*pi)
polar(0.12*theta, 0, 8*pi)
polar(1+cos(theta), 0, 2*pi)
param(sin(3*t+pi/2), sin(2*t), 0, 2*pi)
param(16*sin(t)^3, 13*cos(t)-5*cos(2*t)-2*cos(3*t)-cos(4*t), 0, 2*pi)
param((1+0.35*cos(7*t))*cos(t), (1+0.35*cos(7*t))*sin(t), 0, 2*pi)
sin(x); polar(2, 0, 2*pi); param(t, t^2, -2, 2)
```

依次为玫瑰线、阿基米德螺线、心形线、利萨如曲线、爱心、波瓣闭合曲线及混合绘图。例如：

```sh
cargo run --release --features sixel --manifest-path examples/function-plotter/Cargo.toml -- --sixel --expr 'polar(2*cos(5*theta), 0, 2*pi)'
```

只要包含极坐标或参数曲线，就对两个坐标轴分别估算范围（每条曲线 1025 点，仅接受两个坐标都有限的样本，使用上述四分位距过滤及留白），再根据最终绘图区像素尺寸扩展可见范围，使横纵单位具有相同像素长度。调整尺寸可能改变可见范围，但不会改变参数区间或混合图中普通函数的采样区间。Sixel 下圆不会因宽屏绘图区被拉成椭圆；字符预览只保证 1×2 逻辑栅格中的等比例，实际外观仍取决于终端字体。网格仍为直角坐标网格，不是极坐标网格。

二维曲线使用有预算上限的自适应细分和四边裁剪，非有限值和无法解析的间断不连接。有限采样仍可能遗漏高频细节、窄峰或极窄定义域；这不是隐式方程或符号求解器。

## 验证

```sh
cargo test --manifest-path examples/function-plotter/Cargo.toml --features sixel
cargo test --manifest-path examples/function-plotter/Cargo.toml --no-default-features
cargo run --manifest-path examples/function-plotter/Cargo.toml -- --headless
cargo run --manifest-path examples/function-plotter/Cargo.toml --features sixel -- --headless
```

执行时先设置最终结果状态，再调用 `ctx.commit_frame(Msg::NextPrompt)`。无终端的 `Runtime::step` 返回 `committed`，保留包含栅格元数据的结果快照；下一步才执行后续消息并打开空白提示符。真实终端运行时先渲染并提交历史输出，再继续。

ManualClock 测试覆盖预览的 499/500 毫秒边界、快速编辑合并、错误恢复、历史调取及提交/下一提示符后的取消。其他测试覆盖空白/显式启动、无边框输入、x 区间验证、小正负振幅、常量、多函数合并、非有限样本、小范围刻度、表达式、定义域、渐近线、重复提交、跨提交边界排队的输入、重置后的输入和焦点、有上限的输入历史、Unicode 长度限制、错误提交、图像释放、目标栅格尺寸、原生/字符呈现无重采样、曲线连通性与可分辨间隙、尺寸变化及缓存复用。`--headless` 检查连续成功/错误提交和提示符恢复，不查询终端或输出 Sixel，不能认证真实终端兼容性。`meval 0.2` 的间接依赖 `nom 1.2` 在当前工具链有未来兼容性警告。
