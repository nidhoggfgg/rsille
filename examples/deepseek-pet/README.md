# DeepSeek 终端宠物

在 Unix 交互终端中，从仓库根目录运行：

```sh
cargo run --manifest-path examples/deepseek-pet/Cargo.toml
```

程序在备用屏幕中启动 `$SHELL -i`（未设置时使用 `/bin/sh`）。照常输入命令即可，宠物会自己活动。命令行回显、补全和提示符重绘不会暂停动画：程序把 shell 输出与宠物重绘一起提交；终端支持同步更新时，中间的擦除不会单独显示。收到尚未结束的控制序列时，会等到安全边界才补画宠物。随时按 **Ctrl+]** 关闭整个宠物会话并返回原终端，即使前台程序正在运行也有效；`Ctrl+C` 仍发送给前台程序。也可以在 shell 中输入 `exit`。无需安装后台服务，也不会向原来的 shell 注入输入。

动画只读复用 `../ai-babies/assets` 的 DeepSeek 图集，用程序生成位移和姿态变化。启动时会检查终端是否声明支持 **Sixel**，并使用 rsille 自动探测字符格的像素尺寸；任一项无法确认都会提示并退出，不猜测尺寸。宠物轮廓以外的透明像素不填背景色。宠物以最多 128×128 像素绘制，不再用字符块放大；画面未变时跳过输出，支持同步更新的终端可将一次动画更新整体显示。鲸鱼娘会在慢游和冲刺之间换速；游累了会坐下打盹，醒着时会歪头张望、挥手、眨眼，或蓄力跃起再落地。偶尔还会停下来啃掉面前一格里显示的字符；这不会删除命令输入，也不会向 shell 发送退格键。宠物只叠画在子 shell 输出上，不缓存屏幕：它经过的地方可能留下空白，全屏应用的显示也可能暂时错乱。这不是支持分离和重连的 tmux 会话。
