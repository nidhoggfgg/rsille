# DeepSeek 终端宠物

在 Unix 交互终端中，从仓库根目录运行：

```sh
cargo run --manifest-path examples/deepseek-pet/Cargo.toml
```

程序默认在当前终端的主屏幕中启动 `$SHELL -i`（未设置时使用 `/bin/sh`）。小鲸鱼在整个窗口中游动，直接叠画在 shell 输出上。退出后会话输出保留在主屏幕上。命令行回显、补全和提示符重绘不会暂停动画：程序把 shell 输出与宠物重绘一起提交；终端支持同步更新时，中间的擦除不会单独显示。收到尚未结束的控制序列时，会等到安全边界才补画宠物。随时按 **Ctrl+]** 关闭整个宠物会话并返回原终端，即使前台程序正在运行也有效；`Ctrl+C` 仍发送给前台程序。也可以在 shell 中输入 `exit`。无需安装后台服务，也不会向原来的 shell 注入输入。

使用 **fish 或 zsh** 时，小鲸鱼能认出正在编辑的简单命令。试着键入 `git`：刚打完 `t`，小鲸鱼就可能问「要看看仓库吗？」。继续输入 ` push`，它会换成和远端有关的台词；再加 ` origin main` 时不会重复打断你。`cargo`、`go`、`npm`、`pnpm`、`yarn` 和 `pip` 也有这样的开场。比如输入 `cargo test` 时，它先跟你聊项目，再给测试加油。按回车后它会陪你等，测试通过就挥鳍，出错就吓一跳。fish 在新提示符下直接键入命令时就有预览；用方向键翻历史、Tab 补全或粘贴带终端控制序列的文本时，会在执行时确认命令。zsh 在行编辑器重绘时也能预览这些修改。同一类命令继续加参数时只提示一次。气泡跟着小鲸鱼移动。每句显示后至少停留 1.5 秒，期间如果已经打完子命令、回车并执行完毕，下一句就直接回应执行结果。没有新消息时，气泡约三秒后消失。窗口太窄时只做动作。

试试 `ls -la`、`pwd`、`cd`、`rg`、`find`、`cat`、`mkdir`、`cp` 或 `mv`。小鲸鱼也认识常用的 Git 操作（如 `git diff`、`git commit`、`git pull`）、构建和测试命令（如 `cargo build`、`make`、`go test`、`pytest`），以及 `npm install` 等安装依赖的命令。每类命令在输入、运行、成功时各有三句候选台词，失败和中断也有各自的回应。每次随机选一句，并避开同一组上次说过的话。

在 fish 或 zsh 中，如果 `l` 没有定义，输入它并回车，小鲸鱼会在原地停一停，头顶浮出一个问号，气泡里写着「咦，这条命令游哪儿去了？」之类的台词。它根据简单命令的退出码 127 触发这组台词，所以 shell 报错用什么语言都可以；程序自行返回 127 时也会触发。

命令类别和执行结果通过本地通道传给宠物。管道、复合命令以及其他 shell 继续使用普通的打字反应。如果登录 shell 是 fish，直接使用上面的 Cargo 命令。要在 fish 中显式指定本次会话的 shell，可以运行：

```fish
env SHELL=(command -s fish) cargo run --manifest-path examples/deepseek-pet/Cargo.toml
```

## 组合宠物功能

用 `--features` 列出这次会话要启用的功能，名称之间用逗号分隔，顺序不限。

```sh
rsille pet --features speech,mouse
```

这个组合让鲸鱼待在右下角。使用 fish 或 zsh 时，它会用气泡回应命令；点到它的身体，它会挥鳍。想让它也能追着指针游，把 `roam` 加进列表即可。

| 功能 | 效果 |
| --- | --- |
| `roam` | 自主游动，允许为追鼠标或觅食改变位置。省略时固定在右下角，仍可眨眼和原地做动作。 |
| `mouse` | 左键摸鲸鱼，右键打开互动菜单，也可以在旁边直接拖动小鱼干投喂。配合 `roam` 可追鱼干和指针。 |
| `speech` | 在 fish 或 zsh 中用气泡回应命令编辑、执行和结果。 |
| `command-reactions` | 在 fish 或 zsh 中用动作回应命令，例如成功时挥鳍。可与气泡同时启用。 |
| `typing` | 打字时偶尔抬头看。 |
| `bell` | 听到终端铃声时做受惊动作。 |
| `forage` | 吃可触及的新输出字符。固定时只吃宠物区域内的字符，配合 `roam` 可游过去吃。 |

只要右下角的待机动画，用 `rsille pet --features`。想让它到处游、对命令做动作又保持安静，用 `rsille pet --features roam,command-reactions`。

省略整个 `--features` 参数沿用已有行为。`--quite` 仍可关闭鼠标捕获，`--alt-screen` 单独控制会话使用哪块屏幕。默认会补回鲸鱼和气泡遮住的会话文字，所有功能组合都适用。

## 自定义命令回复

内置规则随程序打包，见 [assets/commands.yaml](assets/commands.yaml)。要添加自己的回复，可以把下面的内容保存为 `my-commands.yaml`：

```yaml
version: 1
groups:
  - commands: ["git status --short", "git status -s"]
    editing: ["只看简短的改动清单？"]
    running: ["我来数数改了几处"]
    done: ["清单在这儿啦", "看完啦"]
```

```sh
rsille pet --commands ./my-commands.yaml
```

从仓库根目录用 Cargo 启动时，把参数放在 `--` 后面：

```sh
cargo run --manifest-path examples/deepseek-pet/Cargo.toml -- --commands ./my-commands.yaml
```

省略 `--commands` 时使用内置规则。自定义文件在启动时加载一次，文件有误时，程序会指出文件路径和原因。

- `commands` 列出共用一组台词的命令。匹配从命令开头逐词进行，最长的完整前缀优先。例如 `git status -s src` 用上面的短清单台词，`git status src` 仍用内置的仓库台词。参数按书写顺序匹配，等价写法可以逐项列出。
- 匹配项用单个空格分词，每个词可含 ASCII 字母、数字和 `-_./+=:@`。用户文件里的同名匹配项覆盖内置项，同组的其他别名保留原回复。同一文件内，每个匹配项在 `groups` 和 `families` 中各只能出现一次。
- `groups` 中每组填写 `editing`、`running`、`done` 三个台词列表。每个列表至少一句，有多句时会避开上次抽中的台词。
- 可选的 `families` 用于刚输入工具名时的开场，每项填写单词工具名列表 `commands` 和台词列表 `editing`。顶层的 `command_not_found`、`failed` 和 `interrupted` 可以分别替换找不到命令、普通失败和中断的台词。

## 显示与交互

要改用备用屏幕，可以运行 `rsille pet --alt-screen`，或在上面的 Cargo 命令后加 `-- --alt-screen`。退出备用屏幕会恢复启动前的画面。这个参数可与 `--quite` 组合。

动画帧随 `deepseek-pet` 编译进可执行文件。小鲸鱼通常占窗口像素高度的三分之一，最大绘制为 **192×192 像素**，窄窗口里会自动缩小。启动时会检查终端是否声明支持 **Sixel**，并使用 rsille 自动探测字符格的像素尺寸；任一项无法确认都会提示并退出。宠物轮廓以外的透明像素不填背景色。姿态和位置都没变化时跳过动画重绘。

小鲸鱼饿了会盯上刚输出的可见 ASCII 字符，游过去吞掉一格，再打个嗝。吃饱后它会有一阵子不再觅食。被吃掉的只是屏幕上的字符，不会修改命令、文件或子进程的数据。屏幕滚动或无法确认字符位置时，它会放弃目标，而不是猜着吃。

小鲸鱼启动时会安静地待在终端右下角。没人打扰时，每次待机持续约 7～15 秒，大部分时间静止，偶尔眨眼或轻轻动一下鳍。歇够了才会慢游、吐泡泡或沿弧线俯冲，活动过后再停下来。

默认可以用鼠标逗小鲸鱼。移动指针时它偶尔会追上来，左键点它的身体，它会挥挥鳍，头顶浮起一颗粉色爱心。在支持的终端中，按住 Shift 拖动即可选字。

第一次摸它时会短暂提示「右键点我，一起玩」。空手时右键点鲸鱼的身体，会在它身边打开互动菜单。小鲸鱼会停下来等你选。点「吹泡泡」或「让它打个盹」会立即做对应动作；点「喂小鱼干」，鱼干会跟着指针走，在想投喂的位置点一下即可放下，也可以按住拖动再松开。点菜单外只会收起菜单。有鱼干时，在任意位置点右键都优先收回鱼干。

也可以直接投喂：在鲸鱼旁边按住左键，会出现一条用 Sixel 绘制的金色小鱼干。拖着鱼干慢慢走，小鲸鱼会跟过来；停住手，它会守着等你松开。松开左键就把鱼干放在那一格，鲸鱼游到后会吃掉。你也可以点一下远处直接投喂，或在它吃到前按右键收回。只开 `mouse` 时，鲸鱼待在右下角，把鱼干拖到它身上再松手就能喂到。手动投喂只需要 `mouse`，吃下的鱼干也会让开启了 `forage` 的鲸鱼暂时吃饱。

要关闭宠物的鼠标捕获，可以运行 `rsille pet --quite`，或使用 `cargo run --manifest-path examples/deepseek-pet/Cargo.toml -- --quite`。鲸鱼照常活动，可以直接拖选 shell 里的文字。前台程序自行启用鼠标时，鼠标事件会原样传给它。

在宠物会话中运行 `printf '\a'`，小鲸鱼听见终端铃声会吓得跳起来，身边闪出一个感叹号。连续响铃时，它要过几秒才会再受惊。即使终端静音，这个动作也能触发。

宠物会跟踪本次会话的可见字符和常用 ANSI 样式。鲸鱼游开、气泡消失或退出会话时，会按行补回原处的文字。窗口滚动后只保留当前屏幕的内容。启动前已有的文字、其他程序绘制的图片，以及终端特有的重排或样式，都可能无法完整恢复。

在大量刷日志的场景下，可以用 `rsille pet --no-restore` 省去额外的输出解析和文字补画。此时宠物经过的地方可能留下空白。在主屏幕上未能取得起始光标位置，或窗口超过 262,144 个字符格时，本次会话也会跳过恢复。

## 添加或替换动画

生成新动作时，使用 [DeepSeek 鲸鱼娘角色参考图](assets/reference/deepseek-whale-girl.png) 保持发型、配色和服装细节一致，尤其是头顶的环形发卷和白围裙上的蓝鲸图案。这张全身像截取自 `ai-babies` 三人原画的左侧，保留了原始像素。制作动画帧时，可对照[现有待机帧](assets/animations/idle/01.png) 确定角色在透明画布上的大小和脚底位置。

[assets/animations/](assets/animations/) 存放小鲸鱼自己的 PNG 帧。每张图使用 **320×320 的透明画布、8 位 RGBA**。同一动作的各帧要对齐鲸鱼身体的位置，游动方向以朝右为准。挥鳍时的爱心、上升的气泡等视觉效果都画在帧里。程序控制触发时机、屏幕位置、跳跃高度和左右翻转。

例如，要把挥鳍换成三帧新动画，将三张 PNG 放入 `assets/animations/wave/`，在 [clips.yaml](assets/animations/clips.yaml) 中替换 `wave` 条目，再重新编译：

```yaml
wave:
  - [wave/01.png, 2]
  - [wave/02.png, 1]
  - [wave/03.png, 3]
```

每项填写相对于 `assets/animations/` 的路径和显示时长。一个时间单位为 100 毫秒，上例的三帧分别显示 200、100 和 300 毫秒，挥鳍在 600 毫秒后结束。可以重复引用同一张图，也可以跨动作复用帧。待机和游泳在行为持续期间循环播放。

调整已有动作只需改图片和清单。要新增一种交互，在清单中起一个小写动作名（如 `nod`），然后在 [src/pet/behavior.rs](src/pet/behavior.rs) 的行为触发逻辑和 `Life::clip` 中接入对应的 `animation::NOD`。构建时会检查清单引用的图片和时长。


功能名统一定义在 [features.rs](src/features.rs)。[session.rs](src/session.rs) 按所选功能接入鼠标、shell 命令钩子和输出字符追踪。[pet.rs](src/pet.rs) 将同一条命令事件分发给已启用的[动作](src/pet/behavior.rs)和[气泡](src/pet/speech.rs)。例如新增一种命令反馈时，可以直接消费这条事件，沿用已有的 shell 钩子。
