# DeepSeek 终端宠物

在 Unix 交互终端中，从仓库根目录运行：

```sh
cargo run --manifest-path examples/deepseek-pet/Cargo.toml
```

程序在备用屏幕中启动 `$SHELL -i`（未设置时使用 `/bin/sh`）。照常输入命令即可，宠物会自己活动。命令行回显、补全和提示符重绘不会暂停动画：程序把 shell 输出与宠物重绘一起提交；终端支持同步更新时，中间的擦除不会单独显示。收到尚未结束的控制序列时，会等到安全边界才补画宠物。随时按 **Ctrl+]** 关闭整个宠物会话并返回原终端，即使前台程序正在运行也有效；`Ctrl+C` 仍发送给前台程序。也可以在 shell 中输入 `exit`。无需安装后台服务，也不会向原来的 shell 注入输入。

动画使用 `../ai-babies/assets` 中每帧 **320×320 像素**的 DeepSeek 图集。小鲸鱼通常占窗口像素高度的三分之一，最大绘制为 **192×192 像素**，窄窗口里会自动缩小。启动时会检查终端是否声明支持 **Sixel**，并使用 rsille 自动探测字符格的像素尺寸；任一项无法确认都会提示并退出。宠物轮廓以外的透明像素不填背景色。姿态和位置都没变化时跳过动画重绘。

小鲸鱼饿了会盯上刚输出的可见 ASCII 字符，游过去吞掉一格，再打个嗝。吃饱后它会有一阵子不再觅食。被吃掉的只是屏幕上的字符，不会修改命令、文件或子进程的数据。屏幕滚动或无法确认字符位置时，它会放弃目标，而不是猜着吃。

小鲸鱼启动时会安静地待在终端右下角。没人打扰时，每次待机持续约 7～15 秒，大部分时间静止，偶尔眨眼或轻轻动一下鳍。歇够了才会慢游、吐泡泡或沿弧线俯冲，活动过后再停下来。

启动时会自动请求终端报告鼠标位置。移动指针时，小鲸鱼偶尔会追上来，可以带着它转向。用鼠标左键点一下它的身体，它会挥挥鳍，头顶浮起一颗粉色爱心。

在宠物会话中运行 `printf '\a'`，小鲸鱼听见终端铃声会吓得跳起来，身边闪出一个感叹号。连续响铃时，它要过几秒才会再受惊。即使终端静音，这个动作也能触发。

收到的鼠标报告会留给宠物，可能影响前台程序的鼠标操作。在许多终端中，可以按住 Shift 拖动来选择文本。

宠物只叠画在子 shell 输出上，不缓存屏幕：它经过的地方可能留下空白，全屏应用的显示也可能暂时错乱。这不是支持分离和重连的 tmux 会话。
