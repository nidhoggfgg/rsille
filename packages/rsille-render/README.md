# rsille-render

English · [中文](README_cn.md)

Terminal buffers, styled Unicode text, bounded drawing and terminal event loops.
Coordinates and dimensions use terminal columns and rows.

Depend on `rsille-render` to import `rsille_render` directly, or use `rsille::render` through the `rsille` crate.

Run from the repository root:

```bash
cargo check -p rsille-render
cargo test -p rsille-render
```
