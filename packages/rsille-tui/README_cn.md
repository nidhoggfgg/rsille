# rsille-tui

[English](README.md) · 中文

应用、可组合组件、布局、焦点、指针手势、动画和后台任务。
同一个运行时支持终端交互与无终端逐步执行。

依赖 `rsille-tui` 可以直接导入 `rsille_tui`，也可以通过 `rsille::tui` 使用相同的 API。

在仓库根目录执行：

```bash
cargo check -p rsille-tui
cargo test -p rsille-tui
```

可运行的组件和运行时示例见[小示例指南](examples/README_cn.md)。
