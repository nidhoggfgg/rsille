# rsille-canvas

[English](README.md) · 中文

彩色采样图形，支持 Braille（2 × 4）、Half-block（1 × 2）和 Quadrant（2 × 2）编码。
绘图坐标以采样点为单位，y 轴向上；边界与输出尺寸以终端字符格为单位。

依赖 `rsille-canvas` 可以直接导入 `rsille_canvas`，也可以通过 `rsille::canvas` 使用相同的 API。

在仓库根目录执行：

```bash
cargo check -p rsille-canvas
cargo test -p rsille-canvas
```
