# rsille 3.0.2

rsille 3.0.2 improves API documentation and release packaging while preserving
the v3 public API.

## Changes

- Replace the README-based crate documentation with a focused usage guide,
  including API selection, a minimal application, and headless testing.
- Fix Rustdoc links and validate API documentation with warnings treated as
  errors for both default and all features.
- Keep the published archive focused on the public source, root READMEs,
  license, and basic Canvas example; remove obsolete migration documentation
  and development records.
- Maintain the rsille coding-agent skill in the dedicated `rsille.skills`
  repository, linked through the `skills` submodule, and update its instructions,
  references, and starter dependency to 3.0.2.

## Validation

- Workspace formatting, tests, and checks for all targets and features.
- API documentation with warnings treated as errors.
- Packaged-crate tests and independent consumers with default and all features.
- Linux PTY checks for synchronous and asynchronous entry, Unicode paste, and
  terminal restoration.
- Skill metadata validation and the starter application's headless tests.

## Use this release

```toml
[dependencies]
rsille = "3.0.2"
```

Enable `syntax-highlighting` for code highlighting. See the package on
[crates.io](https://crates.io/crates/rsille/3.0.2) and the
[API documentation](https://docs.rs/rsille/3.0.2/rsille/).
