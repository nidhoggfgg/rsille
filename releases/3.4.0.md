# rsille 3.4.0

Enable the new `overlay` feature to draw widgets or graphics over a live shell.
The feature re-exports `rsille-overlay 0.1.0` as `rsille::overlay`. Sessions
use a Unix PTY or Windows ConPTY and restore the shell text underneath an
overlay when it moves or hides.

`rsille-render 0.1.2` adds native Windows console queries for character-cell
pixel dimensions and for Kitty and Sixel support. Applications can negotiate
a raster backend before starting their input reader.
