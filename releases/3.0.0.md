# rsille 3.0.0

rsille 3.0.0 brings terminal rendering, composable applications, animation and
sample-based graphics together in one public Rust crate.

## Highlights

- Build applications with `App::new(...).update(...).view(...).run()`, with inline
  and fullscreen modes, explicit exit results and support for existing Tokio runtimes.
- Compose Flex/Grid layouts, text editors, tables, virtual lists, portals and
  draggable, resizable floating windows. Use scoped messages, background tasks,
  subscriptions and shared command routing to manage interaction.
- Draw colored samples with Braille, half-block or 2×2 quadrant encoding. Embed
  a Canvas in a widget tree with world coordinates and matching pointer transforms.
- Animate widgets with gradients, light sweeps, transitions and frosted backdrops.
- Handle Unicode grapheme clusters, mouse interaction and enhanced keyboard input.
- Test applications without a terminal using the step-driven runtime, manual
  clocks and executors, and inspect rendered cells directly.
- Explore the expanded example gallery, including Jellyfish, Lumen, Clockwork,
  Pokémon Battle, Minecraft, Orbit Files and AI Babies, with English and Chinese guides.

## Breaking changes

- Public APIs live under `rsille::tui`, `rsille::render` and `rsille::canvas`.
  Replace v2's `rsille::Canvas` import with `rsille::canvas::Canvas`.
- Canvas stores samples and encodes them when rendered. Color, bounds and
  coordinate APIs have changed.
- The old v2 Turtle and 3D examples are not v3 APIs.
- The repository's `tui`, `render` and `canvas` packages are private development
  targets. Applications should depend on `rsille` and use its types consistently.
- Default features are empty. Enable `syntax-highlighting` for Syntect code highlighting.

See the [example gallery](https://github.com/nidhoggfgg/rsille/blob/v3.0.0/examples/README.md).

## Use this release

```toml
[dependencies]
rsille = "3.0.0"
```

See the package on [crates.io](https://crates.io/crates/rsille/3.0.0) and the
[API documentation](https://docs.rs/rsille/3.0.0/rsille/).

The attached `rsille-3.0.0.crate` is a self-contained Cargo source package;
`SHA256SUMS` records its checksum. GitHub also provides the tagged repository's
source archives below. The showcase programs are examples, not prebuilt binaries.
