# rsille 3.0.3

rsille 3.0.3 fixes terminal colors leaking between cells and frames, including
yellow button backgrounds appearing on borders after keyboard focus moves.
The v3 public API is unchanged.

## Fixes

- Track foreground colors, background colors, and text attributes independently
  in both fullscreen and inline rendering. Cells with an unspecified color now
  restore the terminal default instead of inheriting a previously printed cell's
  color.
- Reset terminal styling before each frame and before clearing the screen, so
  the renderer's style cache matches the actual terminal state.
- Reapply colors after resetting text attributes, preventing stale bold or
  underline styling and avoiding accidental loss of a cell's colors.
- Clear shortened inline content using the default background.

## Validation

- Add ANSI-state regression tests for full frames, sparse differential updates,
  cross-frame styling, attribute resets, and inline height changes. All five
  tests reproduce failures before the fix and pass afterwards.
- Compare a task-manager application's actual colored PTY output with its
  in-memory frame through five keyboard-focus states; all foreground and
  background colors match after the fix.
- Run workspace tests and checks, API documentation checks, packaged-crate tests,
  independent consumers, and terminal-restoration checks.

## Use this release

```toml
[dependencies]
rsille = "3.0.3"
```

Enable `syntax-highlighting` for code highlighting. See the package on
[crates.io](https://crates.io/crates/rsille/3.0.3) and the
[API documentation](https://docs.rs/rsille/3.0.3/rsille/).
