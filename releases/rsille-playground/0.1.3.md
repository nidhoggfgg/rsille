# rsille-playground 0.1.3

Run `rsille pet` in a Sixel-capable Windows Terminal with the new ConPTY
backend. The pet now uses rsille-overlay on Windows and Unix.

Download the executable for your platform from this release, or install with
`cargo install rsille-playground --version 0.1.3 --locked`. On Windows, run
`.\rsille.exe pet` from PowerShell in the download directory.
