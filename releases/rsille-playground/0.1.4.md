# rsille-playground 0.1.4

- Interactive inline showcase launcher when running `rsille` with no arguments
  in a TTY.
- Eliminates Kitty pet flicker in Vim and other alternate-screen apps by
  re-placing the whale, speech/menu panel, and treat without re-uploading
  pixels via `rsille 3.4.2` and `rsille-overlay 0.1.2`.

Download the executable for your platform from this release, or install with
`cargo install rsille-playground --version 0.1.4 --locked`.
