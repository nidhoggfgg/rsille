# rsille 3.0.4

rsille 3.0.4 fixes reversed diagonal glyphs in Quadrant rendering.
The v3 public API is unchanged.

## Fixes

- Encode top-left/bottom-right coverage as `▚` and the opposite diagonal as
  `▞`, rather than swapping them.
- Correct the corresponding glyph-to-Braille conversion in `Canvas::draw_cell`.
- Update regression expectations for coverage and two-color patterns.

## Examples and skills

- Switch AI Babies animations to 2 × 2 Quadrant rendering, with newly sampled
  96 × 48 and 128 × 64 atlases that preserve the displayed aspect ratio.
- Default animation playback to 24 rows; accept 24 or 32 for `--height`.
- Update quadrant exports, animation previews, documentation, and tests.
- Remove obsolete square atlases and rename ChatGPT assets from `dragon-*`
  to `chatgpt-*`.
- Update the skills documentation and starter dependency to rsille 3.0.4.

## Use this release

```toml
[dependencies]
rsille = "3.0.4"
```

Enable `syntax-highlighting` for code highlighting. See the package on
[crates.io](https://crates.io/crates/rsille/3.0.4) and the
[API documentation](https://docs.rs/rsille/3.0.4/rsille/).
