# rsille 3.4.1

The `overlay` feature now re-exports `rsille-overlay 0.1.1`.
`Session::run_with_input` lets a widget send input to the child process.
`WidgetOverlay::draggable_title` turns the top row into a drag handle.
`WidgetOverlay::primary_screen_only` hides a widget and releases its mouse
hit area while the child uses the alternate screen, including in Kitty sessions.

Three runnable examples demonstrate these APIs. `yes_engineer` submits
`yes, continue` with one click, `todolist` shows a session checklist, and
`folder_tree` browses real directories and can change the shell's working
directory.
