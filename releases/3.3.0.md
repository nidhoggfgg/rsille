# rsille 3.3.0

- The `rsille` facade now re-exports the `rsille-render`, `rsille-canvas` and `rsille-tui` crates.
- Inline applications can negotiate Kitty or Sixel graphics with `RasterBackend::negotiate_inline` and pass the resulting `InlineRasterSession` to the renderer.
- Code highlighting moves to the independent `rsille-syntect` crate. Remove the `syntax-highlighting` feature, add `rsille-syntect`, and replace `code_viewer(source).language("rs")` with `CodeViewer::from_lines(rsille_syntect::highlight(source, "rs"))`. Plain source still uses `code_viewer(source)`.
