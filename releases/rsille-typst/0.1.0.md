# rsille-typst 0.1.0

The first release of rsille's independent Typst math rendering extension.
Render formulas in-process into opaque RGB raster canvases, without a Typst
CLI subprocess or adding Typst dependencies to the rsille core.

## Features

- Render Typst math with `MathRenderer`, backed by Typst and typst-render 0.13.1.
- Configure font size, pixel scale, foreground/background colors, and pixel budget.
- Load caller-supplied fonts and reuse the renderer across formulas.
- Preserve compilation errors and expose available warnings through
  `render_with_diagnostics`.
- Integrate the resulting `RasterCanvas` with rsille's existing raster widget.
- Include an inline Sixel demo and headless layout/encoding checks.

## Requirements and limitations

- Depends on rsille 3.1.0 or a compatible release, with default features enabled.
- Input is Typst math-mode contents, without surrounding `$` delimiters;
  LaTeX syntax is not supported.
- Fonts are supplied explicitly. No fonts are bundled in the library, and no
  system-font search or runtime downloads are performed. Font licenses apply
  separately from this crate's MIT license.
- Rendering pixels does not require a terminal. Displaying them through rsille
  requires a compatible Sixel terminal and explicitly configured capabilities.
- File and package access are denied, but this is not a strong sandbox.
  Untrusted formulas require external process isolation and resource limits.
- This is a synchronous single-formula renderer, not a full-document API or
  a formula-result cache.

## Use this release

```toml
[dependencies]
rsille-typst = "0.1.0"
# Optional font source; applications may supply their own fonts instead.
typst-assets = { version = "=0.13.1", features = ["fonts"] }
```

See the [package](https://crates.io/crates/rsille-typst/0.1.0),
[API documentation](https://docs.rs/rsille-typst/0.1.0/rsille_typst/), and
[README](https://github.com/nidhoggfgg/rsille/blob/rsille-typst-v0.1.0/packages/rsille-typst/README.md)
for the quickstart, integration example, and resource limits.
