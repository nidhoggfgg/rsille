# rsille 3.1.0

rsille 3.1.0 adds RGB raster canvases and Sixel terminal graphics alongside
Unicode Canvas, with support for both inline applications and fullscreen TUIs.

## Raster graphics and Sixel

- Add `rsille::raster` (also available as `rsille::render::raster`) for opaque
  RGB pixel storage, clipped drawing primitives, pixel import, and sampling.
- Add `RasterCanvasWidget` to compose pixel graphics with widget layouts,
  clipping, scrolling, and opaque coverage.
- Support Sixel presentation in inline and fullscreen rendering, with explicit
  terminal capability configuration and startup cell-pixel measurement.
- Expose raster integration APIs for external consumers and add regression
  coverage for rendering, viewport bounds, and inline presentation.

## Compatibility and output requirements

- The `sixel` feature is enabled by default. Use `default-features = false`
  to disable the encoder; raster drawing and sampling remain available.
- Displaying raster images requires a Sixel-capable terminal and configured
  capabilities. Measuring cell pixels does not establish Sixel support.
- Raster presentation is Sixel-only: there is no character-based fallback.
  Unicode Canvas remains available for Braille, half-block, and quadrant output.
- Sixel output uses a fixed RGB332 palette and per-cell tiles for precise
  clipping. Source canvases retain their RGB pixels, but terminal output is
  not lossless 24-bit color.

## Examples and documentation

- Add a Sixel windows example and raster modes for AI Babies.
- Add an interactive function plotter with 3D plots, grid composition,
  inline math, and offline RGB preview export.
- Add the independent `rsille-typst` workspace extension for rendering Typst
  math to raster canvases without adding Typst dependencies to the core crate.
- Expand raster API documentation and examples, refocus the English and
  Chinese READMEs on core features, and improve package discovery metadata.

The function plotter preview is an offline RGB export, not a terminal recording;
it does not represent Sixel quantization or refresh behavior.

## Use this release

```toml
[dependencies]
rsille = "3.1.0"
```

For Unicode-only terminal output without the Sixel encoder:

```toml
[dependencies]
rsille = { version = "3.1.0", default-features = false }
```

Enable `syntax-highlighting` for code highlighting. See the package on
[crates.io](https://crates.io/crates/rsille/3.1.0) and the
[API documentation](https://docs.rs/rsille/3.1.0/rsille/).
