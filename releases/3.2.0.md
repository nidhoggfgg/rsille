# rsille 3.2.0

## Fullscreen Kitty graphics

Enable the `kitty` Cargo feature to display full-color raster images with
transparency in fullscreen terminal apps.

```toml
[dependencies]
rsille = { version = "3.2.0", features = ["kitty"] }
```

- Call `.raster_backend(RasterBackend::Auto)` before `.update(...)` to prefer
  Kitty and fall back to Sixel when the terminal supports it. Sixel remains
  enabled by default.
- Select `RasterBackend::Kitty` or `RasterBackend::Sixel` to require a specific
  protocol at startup. Hosts that verify their own terminal capabilities can
  pass a `RasterSession` through `.raster_session(...)`.
- Move Kitty images during drags while reusing the uploaded pixels. If a frame
  fails raster validation, the renderer retains the previous frame's raster
  state for the next update.

## Terminal detection and examples

- Fix Sixel capability detection on macOS.
- Explore the demos through `rsille-playground`. The DeepSeek pet now reacts
  to shell commands and supports a mouse menu and draggable treats.
