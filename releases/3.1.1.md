# rsille 3.1.1

## Transparent Sixel overlays

- Create a transparent source with `RasterCanvas::new_transparent` and draw it
  over managed text or images with `Chunk::raster_overlay` or the raster
  widget’s `.overlay()` builder. Existing replacement rendering is unchanged.
- When an overlay moves or disappears, redraw the current underlying text,
  including wide characters, and restore overlapping images in draw order.
- AI Babies now keeps the terminal background visible in Sixel mode unless
  an explicit `--background RRGGBB` is supplied.

## CLI and examples

- Add the rsille CLI with inline rendering, themes, visual demos, and support
  for Sixel graphics and Typst formulas.
- Add the interactive `deepseek-pet` shell example and switch the function
  plotter to legacy input.
