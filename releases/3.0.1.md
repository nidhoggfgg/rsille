# rsille 3.0.1

rsille 3.0.1 reduces unnecessary dependencies and enabled features while preserving
the v3 public API and the existing Crossterm and Taffy version requirements.

## Changes

- Remove unused direct dependencies on `async-trait` and `rayon`, and the unused
  `env_logger` development dependency.
- Replace the two syntax-highlighting resource initializers with
  `std::sync::LazyLock`, removing the direct dependency on `once_cell`.
- Enable only Tokio's `rt`, `sync`, `time` and `macros` features instead of `full`.
  Applications using additional Tokio APIs should enable those features directly.
- Disable the unused Futures executor by selecting `std` and `async-await`.
- Limit Syntect to bundled syntaxes, bundled themes and the Fancy Regex backend,
  avoiding unused HTML, plist and YAML loading features.
- Update the event-loop documentation to describe the required Tokio time driver.

## Validation

- Workspace tests and checks for all targets and features.
- Packaged-crate tests and independent consumers with default and all features.
- Linux PTY checks for synchronous and asynchronous entry, Unicode paste and
  terminal restoration.

## Use this release

```toml
[dependencies]
rsille = "3.0.1"
```

Enable `syntax-highlighting` for code highlighting. See the package on
[crates.io](https://crates.io/crates/rsille/3.0.1) and the
[API documentation](https://docs.rs/rsille/3.0.1/rsille/).

The attached `rsille-3.0.1.crate` is a self-contained Cargo source package;
`SHA256SUMS` records its checksum.
