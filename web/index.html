02 / rsille-overlay

直接在你正在用的 shell 上作画 Draw directly over your live shell

大多数终端框架只能接管整个屏幕。rsille-overlay 在 Unix PTY 或原生 Windows ConPTY 中运行你原本的 shell，原样透传输出，把可交互组件或 Kitty / Sixel 图像直接浮在上方；移动或隐藏时，被遮挡的文字自动还原。 Most terminal libraries take over the whole screen. rsille-overlay runs your real shell inside a Unix PTY or Windows ConPTY, passes output through untouched, and floats interactive widgets or Kitty/Sixel graphics right on top — cleanly restoring underlying text whenever an overlay moves or hides.

  • 感知你的 shell 活动：Reacts to shell events: 为 bash、fish、zsh 提供会话级钩子，实时捕获 Prompt / Edit / Exec / Done / Read。 Session hooks for bash, fish, and zsh emit Prompt, Edit, Exec, Done, and Read.
  • 可交互的浮动挂件：Interactive floating widgets: 复用全部 rsille-tui 组件，支持标题栏拖动、点击向 shell 发送命令（如浮动目录树一键 cd、待办清单、确认按钮）。 Reuse regular rsille-tui widgets — drag panels, send commands back into the shell, auto-hide on fullscreen apps, or stay interactive over vim in Kitty.
  • 原生跨平台：Native Unix & Windows: Linux / macOS / WSL 使用 PTY，Windows 10 (1809+) 使用原生 ConPTY。rsille pet 正是基于它构建。 Unix PTYs on Linux/macOS/WSL and native ConPTY on Windows 10 (1809+). rsille pet itself is built on it.
查看 rsille-overlay 文档 ↗ Read rsille-overlay guide ↗
overlay_widget.rs · features = ["overlay"] 
use rsille::overlay::{Anchor, Session, ShellEvent, WidgetOverlay};
use rsille::tui::prelude::*;

fn main() -> std::io::Result<()> {
    let app = App::new(String::new())
        .update(|last: &mut String, msg: Option<String>, _| {
            *last = msg.unwrap_or_default();
        })
        .view(|last: &String| {
            row::<Option<String>>()
                .child(label(last.clone()).width(20))
                .child(button("×").on_click(|| None))
        })
        .build();

    let overlay = WidgetOverlay::new(app, (24, 1))
        .anchor(Anchor::TopRight)
        .on_shell(|event| match event {
            ShellEvent::Exec(line) => Some(Some(line.to_owned())),
            _ => None,
        });

    Session::new().mouse(true).run(overlay)?;
    Ok(())
}

04 / Built for Rust Developers

声明界面，不手写事件循环 Describe the UI, not the event loop

view 描述组件，update 处理状态与消息；全屏、Mode::Inline 内联和 live shell 叠加层共用一套 API，并支持无 TTY 内存自动化测试。 view describes widgets, update handles state and messages. Fullscreen, Mode::Inline, and live shell overlays share one API — plus deterministic headless testing without a TTY.

src/main.rs · Mode::Inline + visual effects 
use std::time::Duration;
use rsille::tui::prelude::*;

fn main() -> WidgetResult<()> {
    let exit = App::new(0_u32)
        .mode(Mode::Inline)
        .update(|count, (), _| *count += 1)
        .view(|count| {
            visual(
                button(format!("Count: {count}"))
                    .variant(ButtonVariant::Ghost)
                    .on_click(|| ()),
            )
            .gradient(Color::Rgb(70, 220, 255), Color::Rgb(240, 110, 255), GradientDirection::Horizontal)
            .highlight_sweep()
            .animation(looping_visual_spec(Duration::from_secs(2)))
        })
        .run()?;

    println!("Final count: {}", exit.state);
    Ok(())
}

组合特效，不重写组件 Compose effects without rewriting widgets
